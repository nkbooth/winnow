# Reusable paragraphs — EXAMPLE

**Fictional.** Alex Rivera's, and the test suite's.

These are paragraphs already written in the candidate's own voice, for
situations that recur. The drafter is told to use them where they fit rather
than paraphrase them, because they are better than anything it would write
fresh — and they count as source material, so the claims inside them are
traceable.

## Opening — systems generalist

Fifteen years making the previously-unmeasurable measurable. I tend to arrive
where a process works because a few people carry it in their heads, and leave
when it works because the system does.

## The privacy close

**Use when:** the employer is an open-source, privacy-focused or
security-first company.

I have been a paying customer of tools like yours for years, which is a
different thing from admiring the category from outside. I run my own
infrastructure, I read the source when something surprises me, and I would
rather work on software I already trust than learn to trust software I work on.

## Conceding a gap

**Use when:** the posting names something the inventory does not support.

What I have not done: {gap}. My work has been in {actual context}, and I would
rather talk about how much of that framework survives the translation than
pretend the translation is free.

## Management philosophy

I measure a management job one way: whether the team needs me less each
quarter than it did the quarter before. Hiring is the easy half. The half that
matters is whether the people already there are doing work they could not have
done a year ago.

## Closing

Happy to walk through how the metric definitions actually got agreed on, which
is usually the harder half.
